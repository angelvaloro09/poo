# Interfaces Básicas con JavaFX

Prácticas de interfaces gráficas básicas desarrolladas con **JavaFX**, **FXML** y gestionadas con **Apache Maven**.

---

## Clonar el repositorio

```bash
git clone https://github.com/angelvaloro09/poo.git
cd poo/interfaces-basicas
```

---

## Requisitos

- **Java Development Kit (JDK)**: 21 LTS o superior.
- **Apache Maven**: 3.9 o superior.

---

## Índice de Ejercicios

| Ejercicio | Descripción |
| :--- | :--- |
| [**Ejercicio 1.1**](./ejercicio-1-1/) | Cálculo de edad en años y meses según fecha de nacimiento. |
| [**Ejercicio 1.2**](./ejercicio-1-2/) | Desglose de dinero en billetes y monedas ordenados de mayor a menor. |
| [**Ejercicio 1.3**](./ejercicio-1-3/) | Análisis de cifras (pares, impares, total, mayor, menor) y lista de divisores. |
| [**Ejercicio 1.4**](./ejercicio-1-4/) | Generación de la tabla de multiplicar de un entero (del 1 al 10). |
| [**Ejercicio 1.5**](./ejercicio-1-5/) | Control de gastos semanales: cálculo de total semanal y categoría mayor. |

---

## Ejecución

Para ejecutar cualquier ejercicio desde la terminal, accede a su directorio y corre:

```bash
mvn javafx:run
```

O bien, abre la carpeta del ejercicio en tu IDE preferido (IntelliJ IDEA, Eclipse, NetBeans, VS Code) y ejecuta la clase `Main.java` con clic derecho ➔ **Run**.
