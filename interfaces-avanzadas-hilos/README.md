# Interfaces Avanzadas con Hilos en JavaFX

Prácticas de interfaces gráficas avanzadas y concurrencia multihilo desarrolladas con **JavaFX**, **FXML** y gestionadas con **Apache Maven**.

---

## Clonar el repositorio

```bash
git clone https://github.com/angelvaloro09/poo.git
cd poo/interfaces-avanzadas-hilos
```

---

## Requisitos

- **Java Development Kit (JDK)**: 21 LTS o superior.
- **Apache Maven**: 3.9 o superior.

---

## Índice de Ejercicios

| Ejercicio | Descripción |
| :--- | :--- |
| [**Ejercicio 3.1**](./ejercicio-3-1/) | Conteo de clics y barra de progreso asíncrona de 10 segundos con Threads y Platform.runLater. |
| [**Ejercicio 3.2**](./ejercicio-3-2/) | Simulación concurrente de la fábula de la liebre y la tortuga con Threads y barras de progreso. |

---

## Ejecución

Para ejecutar cualquier ejercicio desde la terminal, accede a su directorio y corre:

```bash
mvn javafx:run
```

O bien, abre la carpeta del ejercicio en tu IDE preferido (IntelliJ IDEA, Eclipse, NetBeans, VS Code) y ejecuta la clase `Main.java` con clic derecho ➔ **Run**.
